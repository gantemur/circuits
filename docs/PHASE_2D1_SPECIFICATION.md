# Phase 2D1 — visual transformations and guided existing examples

Status: implemented on `codex/phase-2d-visual-learning`; this specification was written before implementation. The branch begins at Phase 2C commit `d182c04`; Phase 2C and Phase 2D1 have not been merged or published. This milestone improves the presentation and use of existing analyses and resistor transformations without adding devices, mathematical algorithms, native fields, or a new global workspace.

## Transform workflow

For source-free, finite positive resistor networks, Transform leads through ordered retained terminals, a valid operation and operands, an explicit **Preview transformation** action, physical interpretation, verification, and **Use transformed circuit**. Human-readable candidate descriptions and concrete unavailable-operation reasons replace empty-choice ambiguity. A changed setting or applied circuit invalidates any preview for use. The existing numerical helper remains authoritative: candidate discovery does not imply numerical success. Networks containing sources, controlled devices, or storage are rejected as a whole, with blocker IDs/types and explicit links to suitable existing examples. The separate DC Thévenin/Norton method remains available and gains no unimplemented apply action.

A successful preview has an actual-circuit before/after view, local rewrite illustration where applicable, corresponding retained terminals, marked removed/introduced nodes and branches, and generated values. A local illustration is never labeled as a complete custom circuit. A small deterministic graph may depict generated resistor networks; large/unreliable custom layouts retain exact tables and an explicit limitation. Leading text states the elementary identity and one finite illustrative terminal experiment. For two terminals, apply 1 V between ordered retained terminals. For larger boundary sets, clamp native node `0` to 0 V, one selected non-ground retained terminal to 1 V, and other retained terminals to 0 V. Show ordered voltages and entering currents for original and transformed networks using `I_B=ΛV_B` in SI units. This is a boundary illustration, not another independent equivalence test or a claim that unexcited ports are open. Full matrices, KCL/power checks, differences, topology tables, and strict JSON live in labeled disclosures. Success/failure status stays visible.

**Use transformed circuit** revalidates the helper's native document and only applies a preview matching the current revision and complete selections. The ordinary validated-document change path must update UI references and preserve editor drafts/conflicts. With unapplied Form or JSON drafts, the interface explains the conflict and requires an explicit choice before replacing the applied circuit. A session-only original snapshot permits **Return to original circuit** with the same safeguards. Transform remains open for further exploration; Analyze is a separate action. JSON preview and download remain available. No persistent undo/history framework is introduced.

## Preset drawings and study guide

All 14 existing presets—eight original, three resistor, and three Phase 2C port examples—have verified whole-network schematics. The six currently table-only presets receive explicit layouts: series, star, bridge, resistor T, RC section, and connected RC sections. Draw actual ordered terminals, nodes, ground, source polarity and sensing where present, observation/port markings, exact IDs, and current values. Components remain keyboard-selectable and linked to the inspector. Existing valid drawings are preserved. Layout matching compares conservatively with the actual topology; custom circuits retain an accurately named table fallback. The exact topology table remains available as an expandable view for drawn presets.

A shared collapsible **The mathematics & suggested experiments** guide is visible from Analyze and Transform for the selected preset, with its open state preserved. Each existing example gets an English/Mongolian question, assumptions and boundary conditions, equation or baseline reference, two or three concrete workspace-qualified experiments, and an interpretation prompt. Guide actions navigate without changing the circuit or silently replacing panels; an existing appropriate panel is focused, while a full three-panel layout requires an explicit replacement choice. A custom circuit without an authored guide is labeled as such. After a transformation the guide identifies its original teaching context and marks references as baseline targets.

App-level authored scalar reference metadata records quantity (`H`, driving-point `Z`, or driving-point `Y`), units, ordered input/output or port, source/load and zero-state conditions, variable/frequency scaling, baseline fixture, formula, and optional finite rational coefficients with declared order. Independently derived records are required for the divider, RC low-pass, RC high-pass, and series resistor impedance. No general expression engine or synthesis implementation is added. A changed circuit never displays baseline coefficients as its current computed response. Foster/Cauer synthesis concerns admissible driving-point functions; voltage-transfer realization is a different problem.

## Mathematical and architectural boundary

Preserve all Phase 2C and earlier numerical algorithms, arithmetic order, tolerances, failure classifications, and independent physical checks. New illustrative calculations explicitly document dimensions, units, terminal/current signs, governing equation, finite-range failure, and limited evidentiary meaning. Keep layout/lesson/reference metadata separate from native v1 circuit semantics and core numerics. No richer filters, transformers, gyrators, nonlinear devices, synthesis algorithms, symbolic extraction, arbitrary autorouter, schema change, or inactive Synthesize view.

### Pre-release presentation correction

Compact resistor drawings now require continuous leads to exact terminal centers and reject geometry in which a wire or symbol reaches an unrelated node or branches cross without a junction. A rejected layout displays exact topology tables. Position maps preserve prototype-property IDs, and the boundary sentence renders markup-like IDs literally. Finite currents remain labeled in amperes when milliamp conversion overflows. Preset RC capacitor and circular-source leads meet their symbols. The numerical helper and native document are unchanged. Findings, focused regressions, full checks, and browser evidence are recorded in [DECISIONS.md](DECISIONS.md#phase-2d1-presentation-correction--11-october-2026).
