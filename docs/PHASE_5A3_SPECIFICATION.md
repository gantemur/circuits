# Phase 5A3 — browser RC synthesis laboratory

Starts from accepted headless commit `59b4df7`; released main remains `30c2857`. Add a bilingual Synthesize workspace without changing kernel mathematics, schemas or numerical tolerances. No merge/deployment or LC/RL/general RLC work.

## State and execution

Analyze/Transform retain the shared native document. Synthesis has separate session-only exact text, primary quantity, coefficient arrays (comma-separated ascending powers), reference scales, method selection, and optional domain-specific Foster decompositions (one pole/coefficient pair per line). Worked targets are principal, pure R, pure C, finite-DC RC and irrational-pole Cauer. The interpreted pending polynomial is shown before Run, explicitly unvalidated.

Explicit Synthesize runs selected methods sequentially in one dedicated embedded Blob Web Worker. No synchronous synthesis fallback, typing/render/language-triggered calculation, or fourth published asset. Owned tokens and complete snapshots reject stale replies. Edits permanently retire corresponding result eligibility even if text is restored; primary/scales invalidate all, method-specific decomposition edits invalidate that method. Any running batch is terminated on scientific edits, cancel, leaving Synthesize or page hiding. Completed unaffected results persist. Language/layout changes preserve scientific state. Worker unavailable/error is separate from kernel outcomes.

Foster I always receives the exact impedance polynomial; Foster II receives the exact admittance polynomial, with exact array exchange for a reciprocal, rejecting an original zero denominator before exchange. Zero primary functions route through the accepted Cauer boundary handling before reciprocal construction. Empty optional decompositions pass target-only requests and report unavailable, not nonrealizability. No pole inference or fitting.

## Evidence, drawings and adoption

Results retain exact mathematics, native conversion and numerical verification as three separate evidence layers. Display exact reconstructed target, normalized/SI components, endpoint limits, trace, rounding discrepancies and measured Z/Y with differences/limits; long exact details are expandable. Comparison tables describe sampled checks, distinct from exact identities. Technical kernel details may stay English inside an explicitly labeled disclosure; all summaries/actions/teaching are bilingual.

Use bounded verified layouts for small generated Cauer/Foster structures, matching every actual native edge; larger/unmatched structures use explicit topology tables. Rectangular R symbols and capacitor plates have connected leads and labeled actual nodes. Results stack at mobile widths with locally scrolling diagrams/tables, no page overflow.

Apply is enabled only for current certified, strictly generated and numerically passed results. Current certified/generated but numerically unresolved or mismatching documents may be exported explicitly as unverified JSON for inspection, with a warning; they cannot Apply. Stale/cancelled/running results cannot export or apply. Adoption goes through strict native import; existing Form/JSON drafts require confirmation and remain intact with conflicts. Preview alone never changes the circuit. No Return action is added. After adoption, an explicit Analyze action adds a one-port frequency panel at (port,0) and the verifier’s reference-frequency sample; at the three-panel limit the user selects a replacement. Existing panel settings are never silently repurposed. The handoff is valid only while that adopted native snapshot is still current.
