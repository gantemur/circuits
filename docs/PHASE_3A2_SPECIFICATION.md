# Phase 3A2: browser diode teaching lab

## Boundary and scientific contract

Phase 3A2 integrates the reviewed Phase 3A1 memoryless Shockley-series diode kernel into the existing bilingual browser lab. The native browser document is a discriminated union: strict v1 linear circuit plus v1 experiment, or strict v2 circuit plus v1 experiment. Parsing, editing, copying, and export preserve the version, exact IDs, all scientific fields, and the original strict validators. Browser panel state, solver traces, caches, and tangent provenance stay outside native JSON. A valid circuit with an unsolved bias remains applied and reports an analysis failure. The v1 parser and linear kernel remain unchanged.

The shared selector gains four browser copies of the nonlinear fixtures, for 26 examples; the divider remains first and default. The two single-diode copies have distinct device IDs so topology matching survives value edits. Source AC increments may be 1 mV RMS in browser copies only. Drawings are conservative, topology-matched, connected, and parameter-aware; custom topology falls back to the exact table. The existing Form and JSON editor, inspector, three independently configured panels, workspace navigation, and draft/conflict protections remain.

## Analysis dispatch

Capability dispatch precedes every legacy linear API. On v2, DC solves the nonlinear operating point; Frequency solves DC with all declared source values, creates a provenance-checked v1 tangent, then uses the existing frequency engine for incremental transfer and configured RMS AC. Equations distinguishes the augmented nonlinear residual/Jacobian from the reduced tangent `E δxdot + KQ δx = B δu`; their coordinate counts can differ. Transient, port analysis, and Transform explicitly explain their Phase 3A2 unavailability on v2, preserving panel settings. Diode characteristic and DC source sweep are the only new panel types. Bias-dependent results never reuse an obsolete or failed bias. A 64-unknown pre-assembly limit bounds new nonlinear browser calculations and leaves v1 analysis limits unchanged.

The operating point presents terminal voltage, signed current, and local differential resistance first. Expandable detail contains junction values, voltages/currents, physical versus binary64 arithmetic residual allowances, signed powers, and Newton trace. Iteration count is algorithmic, not physical time. Absolute source waveforms and storage initial values remain stored but do not set DC bias or incremental frequency response.

## Characteristic and sweep

The characteristic samples signed terminal `(V,I)` with bounded per-panel voltage range and sample count. At `Rs=0`, `I=Is expm1(V/eta)`; at `Rs>0`, solve the monotone relation `V=vj+Rs Is expm1(vj/eta)` without mistaking junction voltage for terminal voltage. Failed/nonfinite samples are gaps. The solved Q marker and optional local tangent appear only for a current valid bias. Fit to bias is explicit and edits do not reset accepted ranges. An external load line `I=(E−V)/R` appears only after exact topology and orientation checks establish one source, one resistor, one diode in series, optionally with a parallel DC-open capacitor. Internal `Rs` remains in the diode law, not the external resistor. Coupled antiparallel networks receive no single-diode load line.

The DC sweep selects one existing independent source, named observation, finite ordered bounds, and 2–121 linear samples. Explicit Run/Cancel yields between points. Each point copies the applied document, changes only the selected source's `dc`, and solves with the existing operating-point API; a prior successful coordinate may warm-start the next point. Failures have null output and explicit status, and no failed iterate seeds a later point. The applied document and cached current bias remain unchanged. Version/settings/panel/visibility changes invalidate a run; late results cannot overwrite newer data. CSV has stable scientific headers, units, sampled values, outputs, and statuses, and is unavailable for obsolete/incomplete results. The sampled branch is not a uniqueness or hysteresis certificate.

## Editing, language, and acceptance

Form editing supports ordered diode terminals and explicit `Is` (A), ideality factor, internal `Rs` (Ω), and `T` (K), defaulting to `1e-12`, `1`, `0`, and `300`. Adding D promotes a v1 draft to v2; removing the last D does not downgrade v2. Applying uses strict validation; invalid text remains pending without changing the analyzed circuit. The inspector edits the same native parameters, distinguishes read-only differential resistance from `Rs`, and scopes pending text to document identity. English and Mongolian translate labels, errors, progress, guides, and accessibility names at render time; exact scientific IDs, formulas, SI units, JSON fields, and CSV headers remain stable.

Desktop uses the existing two-column panel arrangement; 390/320 px use one column with local scrolling for plots, matrices, and drawings. Legends use text/line styles in addition to color. Four guides teach load-line bias, local versus ratio resistance, internal series drop, coupled antiparallel behavior, bias-dependent RC response, and the partial temperature model through concrete panel actions. Fresh examples receive suggested panels; existing configured panels are preserved unless the student explicitly restores the suggestion.

Independent acceptance uses the Phase 3A1 baselines and scalar load-line solutions, checks the constructed `Rs=10 Ω` point, and verifies diode–RC local `H_Q(s)=(1/R)/(1/R+gterminal+sC)` with `H_Q(0)≈0.05079738878658121`, `fc≈3133.132369472074 Hz`, and `H_Q(j2πfc)≈0.025398694393290604(1−j)`. Tests cover strict v1/v2 routing and round trips, four presets, form/inspector drafts, failed bias, characteristic inversion and polarity, eligible/ineligible load lines, sweep failures/cancellation/invalidation, duplicate panels, stale references, incremental AC distinctions, and retained linear behavior. Actual browser checks cover both languages, all four examples, editor and panel workflows, desktop/390/320 px, console and overflow, with file-picker/download limits reported separately. This task branch is not a published release.
