# Phase 3A4: browser nonlinear transient teaching lab

This task branch integrates the reviewed Phase 3A3 `nonlinearTransient` solver into the existing bilingual Analyze Transient panel. The public `main` site remains the Phase 3A2 release until a separate release review. Strict v2/experiment-v1 native documents and their time waveforms are the scientific inputs; panel settings, run identity, sample selection, results, and lessons are browser-only state. V1 transient behavior remains unchanged, and v2 port analysis and Transform remain unsupported.

## Scientific and execution boundary

A run starts at zero, with finite positive duration no greater than 10 s and nominal step. The browser conservatively preflights at most 3000 accepted intervals, including source-event grid restarts, and an augmented initialization matrix of at most 64 unknowns. The worker calls the kernel once with an owned document/options snapshot and its own 3000-interval, 64-unknown, 60-correction, 30-backtrack limits. It neither reimplements Newton nor changes kernel tolerances, initialization, source-event handling, or failure classifications. No diode charge, ideal switching, adaptive stepping, periodic-state certification, or arbitrary start control is introduced.

The actual native waveform drives time analysis. Absent waveform means declared DC; a waveform offset is not added to DC. Sinusoidal time amplitude is peak, while frequency-panel AC phasors are RMS and do not drive transients. Equilibrium freezes actual initial left-side time sources, potentially differing from declared DC; prescribed storage need not have a DC root. Across supported source steps, capacitor voltage and inductor current remain continuous while algebraic coordinates and compatible currents may jump. A smooth diode zero crossing is not a source event. A converged numerical trajectory is not evidence of uniqueness, stability, periodic state, or physical diode-model accuracy.

Only one nonlinear transient worker may run across the app. Run owns a unique token, panel ID, document revision and object, and accepted settings. Cancel terminates the worker. Applied scientific edits, accepted setting edits, invalid pending text, missing output, panel type/removal/collapse/replacement, departure from Analyze, and page hiding permanently retire active and completed runs. Language, ordering, width, unrelated panel settings, and reopening settings do not. A late worker message cannot revive a retired result. Worker creation, runtime, message, and unavailable-execution errors have distinct visible outcomes. No main-thread fallback is allowed.

## Presentation and examples

The selected named observation and its unit lead the result. Preserve every accepted regular/left/right sample, including duplicate timestamps. Event discontinuities are vertical rather than finite-duration slopes; an expandable event table exposes both sides. A source-voltage overlay is available for the four new voltage-output lessons and uses each accepted sample's actual source values. Current and voltage never share one unlabeled axis. Numerical failures retain the real accepted prefix and expose stage, time, stable code, and an endpoint marker. Empty or single-time prefixes have explicit prose and values. Detailed per-sample tables expose exact-ID observations, sources, unknowns, diode and storage values, signed currents/powers, A/V residuals, ground KCL, W/J physical and arithmetic allowances, and Newton corrections. Compatible instantaneous capacitor current at initial/event samples differs from regular backward-Euler interval current. Backward-Euler dissipation is numerical; event samples have no zero-duration interval-energy identity; arithmetic allowances are estimates, not certified bounds. Sample inspection does not alter the cached DC Q point.

Four browser copies of the reviewed fixtures extend the selector from 26 to 30: diode-RC step (0.5 ms, 10 µs; Transient/DC), biased sinusoid (3 ms, 5 µs; Transient/Frequency), half-wave rectifier (40 ms, 100 µs; Transient/Characteristic), and smoothed rectifier (60 ms, 100 µs; Transient/DC). The divider remains first and default. Preset identity and topology matching are separate so similar diode-RC circuits cannot acquire the wrong guide after edit/import. Each new circuit has a topology-verified, connected, parameter-aware drawing; custom topology uses the exact table. English/Mongolian guides focus or add a suitable panel without overwriting configured panels or starting a run.

CSV is available only for a current completed success or numerical failure with accepted samples. It records stable headers, exact output ID and unit, time, side, actual interval, current convention, status and failure stage/code, preserving duplicate timestamps and quoting exact IDs. Failed iterates do not acquire fabricated output values. Native JSON export contains no transient browser state.
