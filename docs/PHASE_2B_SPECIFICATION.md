# Phase 2B — passive resistor transformations

Status: task-branch implementation specification, 11 October 2026. This milestone extends the released UX Transform workspace. The native v1 schema and existing Thévenin/Norton experiment remain unchanged. The public acceptance cases below are self-contained; no private reference is needed to build or test them.

## Scope and convention

The input is a validated source-free network containing only finite, strictly positive resistors. Any source (including a zero-valued source), controlled source, capacitor, or inductor gives an explicit unsupported outcome. This is an implementation boundary, not a restriction on the mathematics of Schur complements. Each resistor has ordered terminals `(p,n)`, voltage `V(p)-V(n)`, and current `(V(p)-V(n))/R` from `p` to `n`. For reduction the full ungrounded Laplacian includes node `0` as an ordinary node. An ordered nonempty set `B` of retained terminals defines internal nodes `I`; every connected component must meet `B`. Terminal current enters the network and satisfies `i_B=Λu_B`, with `Λ=L_BB−L_BI solve(L_II,L_IB)` in siemens. Do not invert `L_II`, silently ground `0`, discard disconnected nodes, or infer internal voltages from terminal equivalence.

## Operations

Users explicitly choose an operation and operands; the UI may offer conservative valid candidates but performs no automatic search. Parallel combines two selected resistors between the same unordered endpoints by adding conductances. Series combines exactly two branches meeting at a nonretained degree-two node with distinct outer neighbors. Star–mesh eliminates one nonretained center with at least two distinct neighbors: sum parallel center-to-neighbor conductances `g_i`, put `G=Σg_i`, and add each coupling `g_i g_j/G` to any existing neighbor connection. Star→delta is the three-distinct-neighbor instance with no other center branches. Delta→star replaces the three selected sides of a triangle by a collision-free internal center, with `S=R_ab+R_bc+R_ca`, `r_a=R_ab R_ca/S`, `r_b=R_ab R_bc/S`, `r_c=R_bc R_ca/S`; other branches, including parallel triangle sides, remain. Kron eliminates all nonretained nodes in one operation. All operations preserve the full ordered terminal response, not one effective resistance.

Every preview works on copies. A success includes applicability and changed-component explanation, original/transformed topology, eliminated/introduced nodes, both terminal response matrices, and a numeric agreement check. It offers transformed native JSON only after strict validation and finite realization. The preview does not replace the analyzed circuit or either editor draft. Users can load that JSON through existing import/editor controls. The generated document retains node `0`, has a source-free equilibrium experiment and valid boundary-voltage observations; internal-voltage and branch-current observations of the original are not claimed preserved. Recompute after every validated circuit or selection change and never offer stale export. Transform method, ordered exact-ID terminal selectors, drawing choice and applicable settings survive navigation/language changes. Missing terminals require explicit reselection. The Analyze port-panel Open comparison action selects the DC method and transfers its ordered port and load; ordinary method navigation retains resistor settings.

## Numerical evidence and failures

Compare matrices in siemens with stated absolute and relative limits; check symmetry, zero row sums, nonpositive off-diagonals, and finite entries. Test independent boundary voltage vectors including a common shift, solve internal KCL in a gauge fixed at one retained voltage, and evaluate KCL and boundary currents from branch voltage differences `(V(p)−V(n))/R`. A constant terminal voltage then gives zero branch current without subtracting large common-mode Laplacian terms. The absolute current floor is in amperes; the relative internal-KCL term scales with incident branch-current magnitudes. For each terminal, compare currents against the existing absolute and net-current relative limits **plus** an arithmetic allowance based on the sum of absolute incident branch currents, not only their cancelling net. Include measured internal KCL residuals and their branch-evaluation allowance: in a passive network, correcting an internal residual redistributes no more than its absolute injected current to one boundary terminal. Every term has amperes as its unit. This is a floating-point diagnostic budget, not a certified bound or a replacement for the separate matrix and internal-KCL tests. Check physical dissipated power `P=uᵀΛu` in watts using relative boundary voltages (the Dirichlet energy is `P/2`). Analytical rules are identities; computed checks are floating-point evidence. Surface failed solves, disconnected internal components, overflow, destructive underflow, nonfinite values, and unrepresentable generated resistors as explicit failure. No clipping, absolute-value repair of wrong signs, implicit weak-edge deletion, or successful nonfinite export.

## Acceptance

- Series `1000+2000=3000 Ω`; reversed-orientation parallel `1000 || 2000=2000/3 Ω`.
- Star conductances `1,2,3 S`, retained neighbor order `(a,b,c)`, have response `[[5/6,-1/3,-1/2],[-1/3,4/3,-1],[-1/2,-1,3/2]] S`, delta sides `R_ab=3 Ω`, `R_ac=2 Ω`, `R_bc=1 Ω`; the reverse delta has star legs `(1,1/2,1/3) Ω`.
- A four-terminal star creates all pair couplings. A five-resistor unbalanced bridge has no initial **series/parallel** move while bulk Kron succeeds; verify it against independently solved internal KCL. Its degree-three internal nodes *do* admit star–delta, so claiming no elementary transformation of any kind would contradict the stated rules. Different valid elimination orders agree with bulk Kron.
- All-retained and reordered terminals, parallel neighbors, invalid retained/branched series, unsupported devices, missing/disconnected terminals, ID collisions, extremes, input immutability, strict JSON round-trip and editor-draft preservation receive explicit checks.
- Uniformly scaled star/delta identities, including the 0.0001 scale and reversed terminal orders, must pass the current and power checks. Candidate identities must distinguish arbitrary valid edge IDs such as `a:b` and `b:c`. Ordered selectors must preserve native IDs containing commas or whitespace through preview and strict export.
- For a four-terminal star with conductance weights `[5,7,3,1]/s` and `s=10⁻⁴ Ω`, the response is `(diag(w)−wwᵀ/16)/s`. At `[1,2,3,4] V`, its center is `2 V` and terminal currents are `[-50000,0,30000,20000] A`. The zero net at `b` still has about `43750 A` of incident absolute branch-current magnitude in the generated mesh. Test several scales and terminal orders. Test `[3,7,3]/s` at `s=10⁻⁶ Ω`, its delta inverse, and the existing extreme-value failures.
- The browser displays the new method next to unchanged DC one-port; source-free examples open with sensible DC Analyze defaults. English/Mongolian controls, readable topology, scrollable matrices and failure messages work at desktop, 390 px and 320 px. Existing mobile Original/Equivalent drawing behavior remains confined to drawings. Browser checks distinguish actual file/download interactions from automated serialization.

No dynamic reduction, general two-port parameters, nonlinear analysis, synthesis, Bott–Duffin/Darlington construction, or graphical wiring editor is included.

## Task-branch verification

The implementation is on `codex/phase-2b-resistor-transforms`, not on `main` or the public site. The new independent acceptance tests cover the stated identities, an independently solved bridge KCL system, sequential elimination orders, invalid selections, numeric extremes, strict JSON round-trip, and immutability. The full suite passed 81/81 after `npm ci`; typecheck, kernel build, site build, and `git diff --check` passed. In the actual local browser, all six method controls produced previews on applicable circuits, including reversed parallel and delta→star after applying a generated preview through the JSON editor. Explicit operand choice, mobile topology switching with response matrices still visible, translated failure/missing-terminal states, unapplied form/JSON draft preservation, and the existing divider Thévenin/Norton result were checked. English and Mongolian at desktop, 390 and 320 CSS px had no page overflow; browser console errors were absent. The browser automation did not deliver file-chooser or completed download events, so those particular interactions were not verified, although strict serialization and JSON-editor application were.

No `.local-reference/book` copy was present in the checkout; Chapter 1 §§1.3–1.4 and Appendix C.3 could not be inspected directly. The implementation and public tests use the self-contained equations above and the published mathematical conventions.
