## Contract

Graphical Save project exports a completed independent draft as `.cuf.json` through
exportProjectDraft, serializeProject and projectContentKey. All property/tool text,
wire and move gestures block saving. Download initiation is not disk durability.
The last exported/opened content key is independent of the scientific Apply
checkpoint; viewport participates. Native JSON import/export stays unchanged.

Open has its own file input, checks size before reading, parses strictly, and
previews a fully validated candidate plus warnings before explicit replacement.
Replacement touches only Graphical. It resets history and keeps the loaded graph
independent, including when v2/v3 is applied. Apply remains an explicit shared
native transition. Invalid drawing with supported validated native data offers an
explicit provisional-layout fallback. Unsupported scientific models stay intact.

Each async attempt captures document identity/revision/exact serialization, draft
identity/scientific/geometry revisions, and monotone interaction generation plus
pending/gesture/viewport state. Recheck after reading and before installation.
New attempts supersede old attempts. Edit-and-restore cannot revive authorization.
Language-only rendering does not invalidate ownership. Consent identifies only
Graphical replacement; Form/JSON and current analyses remain untouched.
