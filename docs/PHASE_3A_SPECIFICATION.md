# Phase 3A: nonlinear DC and local linearization

## 3A1 contract and boundary

Phase 3A1 is a headless, browser-compatible TypeScript kernel for a memoryless diode, its DC operating point, and a local tangent circuit. Phase 3A2 may integrate this work into the browser. The released browser remains a linear v1 lab. This phase does not add nonlinear transients, charge storage inside a diode, breakdown, ideal-diode complementarity, temperature-dependent saturation-current laws, transistors, SPICE import, or graphical diode editing.

The existing v1 document/parser/serializer and linear analysis APIs retain their behavior. A separate strict document has `circuit.schemaVersion: 2`, `experiment.schemaVersion: 1`, all existing linear devices and experiment fields, and `D` branches. A diode has ordered `p` (anode) and `n` (cathode) terminals and an explicit `model` with `kind: "shockley-series"`, `saturationCurrentA > 0`, `idealityFactor > 0`, `seriesResistanceOhm >= 0`, and `temperatureK > 0`; all numbers must be finite. Unknown fields, models, versions, references, and duplicate IDs fail validation. Exact IDs are retained. The v1 browser importer continues to reject v2.

At DC, every independent source uses its `dc` value. AC values, waveforms, and initial storage values do not determine the bias. Capacitors have zero current; inductors have zero voltage. All four controlled-source laws remain those of v1. Current-controlled devices still require a retained voltage-source-type sensing branch. API input is validated and copied before solving. A diode-free v1 document uses the existing `assemble`/`solveDC` path.

## Device law and assembled equations

Use SI units, `kB = 1.380649e-23 J/K`, `q = 1.602176634e-19 C`, `VT = kB T/q`, and `eta = idealityFactor VT`. The supplied `Is` applies at the stated temperature; this model changes only `VT` with `T` and does not infer `Is(T)`, `Rs(T)`, or self-heating.

With `v = V(p)-V(n)` and positive `i` from p to n, `vj = v-Rs i` and `rD = i-Is expm1(vj/eta) = 0`. One current unknown per diode is appended after the v1 MNA unknowns, in sorted diode-ID order. The p and n KCL rows receive `+i` and `-i`; coincident terminals cancel by addition. Its new row has amperes as units. The analytical Jacobian uses `gj = Is exp(vj/eta)/eta`: derivatives with respect to p voltage, n voltage, and diode current are `-gj`, `+gj`, and `1+Rs gj`. The first two have siemens; the last is dimensionless. Existing KCL rows have A, voltage/inductor constraint rows V, node unknowns V, and branch-current unknowns A. All numeric range failures are explicit; no exponential clipping or hidden conductance is allowed. `expm1` is used near zero and `gj` is evaluated without forming `i+Is`.

## Newton and physical acceptance

Solve `J(xk) Δx = -F(xk)` using the existing equilibrated linear solver, then try `xk+alpha Δx`, with bounded halving backtracks. Unknown order and the default all-zero initial guess are deterministic. Option values and optional initial coordinates must be finite and dimensionally valid. The line-search merit is the maximum of KCL residual magnitudes divided by a fixed current scale (A) and branch-law residual magnitudes divided by a fixed voltage/current scale according to their row labels. Unless explicitly supplied, the fixed current scale is the maximum of 1 mA, prescribed DC current magnitudes, `Vnom/R` for resistors, and `|gain|·Vnom` for VCCS branches, where `Vnom=max(1 V, magnitudes of declared DC voltage sources)`. This is a globalization weight, not a physical acceptance tolerance. Scales are chosen before the search, so a trial cannot win by changing its denominator. The trace records the accepted alpha, merit, and maximum voltage/current correction magnitudes. A rejected nonfinite trial may be backtracked; exhausted iterations, backtracks, unusable initial evaluation, and unresolved numerical range fail explicitly.

A small step or falling merit alone never establishes success. Original unclipped equations must pass unit-aware row checks. The physical allowance uses the row-unit absolute floor plus the relative tolerance times noncancelled physical contributions: branch currents in KCL, branch/control voltage differences or controlled-current voltage drops in constraint rows, and diode current/model current in diode rows. A separate binary64 allowance, `8·(expanded operand count + 1)·ε·sum|expanded operands|`, covers roundoff in the actual matrix/source evaluation and terminal subtraction. Both parts have the row's A or V unit and are reported separately. This conservative first-order diagnostic is not a certified error enclosure. A common node potential cannot inflate the physical relative allowance; if a small branch voltage is lost when large node potentials are subtracted, no residual check can recover that information. Check the final Jacobian for finite values and regularity. A singular correction system describes that linearized subproblem; it does not prove global nonexistence or nonuniqueness. A converged root does not establish global uniqueness or dynamical stability.

Report node voltages, signed branch currents and observations, diode `v`, `vj`, `i`, `gj`, terminal conductance and differential resistance (or explicit unavailable state), physical rows including reconstructed ground KCL, and signed absorbed powers. For each diode check `v i = vj i + Rs i²`. The global power sum has watts and is compared with a dimensioned tolerance based on uncancelled device-power magnitudes; any unresolved physical check is a failure. Never return success with a nonfinite coordinate, observation, residual, power, or Jacobian entry.

## Tangent circuit

For a regular solved bias, `gterminal = gj/(1+Rs gj)` and `rd = Rs+1/gj`. The tangent operation verifies that the supplied current circuit and independent-source DC values match the owned solved bias. Fingerprints validate strictly before normalizing to the owned JSON representation: absent optional labels match optional labels set to `undefined`, while unsupported fields and invalid values still fail. AC phasors, waveforms, and absolute storage values do not affect this memoryless bias. It replaces D branches with R branches of the same IDs and terminals, preserving current observations and every linear/controlled branch. The resulting native v1 experiment retains independent-source coordinates and the current document's explicitly declared AC increments, sets DC increments to zero, omits large-signal waveforms, and uses zero incremental storage values. Bias/provenance metadata is returned outside the native document. Unrepresentable finite positive `rd` gives a limitation result. Eliminating the diode-current unknown from the Jacobian must give the same terminal conductance; local DC sensitivity and frequency response run through the existing linear engine. This circuit is in delta variables and therefore contains no affine bias offset. A unit-input transfer is a derivative, not a claim about a finite 1 V nonlinear response.

## Acceptance and reading path

Independent fixtures and scalar equations check the two distinct book benchmarks at `VT=0.025` and `VT=0.02585`, a constructed `Rs=10 Ω` bias, antiparallel diodes with positive/negative drives, and a biased diode with external parallel capacitor. Tests also cover controlled sources, analytical Jacobian versus scaled central differences, tangent sensitivity versus neighboring nonlinear biases, RC local frequency/pole, actual damping, bad options/models, degeneracy, contradictory constraints, forced reverse current below `-Is`, finite range, stale bias, exact IDs, ownership, and v1/browser rejection compatibility. Expected values must not be generated by the production Newton solver. The headless demo prints the model, bias, signed currents, residuals, trace, differential quantities, tangent, and frequency response. The student path is model law → residual/Jacobian → Newton correction → physical checks → tangent linear analysis.
